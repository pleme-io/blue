# blue language reference

Generated by `gen/reference.b` from `blue reference`, which reads the tables the implementation runs on. Do not edit by hand: run `nix run .#regen`, and the `generated-reference-fresh` check fails when this file is stale.

Semantics that differ from Ruby are in [`bidamas/okite/RULES.md`](../bidamas/okite/RULES.md). Packages and their definitions are in [`bidamas/CATALOG.md`](../bidamas/CATALOG.md). Idiomatic programs are in [`EXAMPLES.md`](EXAMPLES.md).

## Surface forms

| write | lowers to | meaning |
|---|---|---|
| `42` | `42` | An Int. Underscores may separate digits: 1_000. |
| `3.5` | `3.5` | A Float. |
| `"text"` | `"text"` | A string. Escapes: \n, \t, \", \\, \u{1b}. |
| `"n = #{n}!"` | `(concat (concat "n = " n) "!")` | Interpolation: any expression inside #{…}, rendered with to_s. A literal that must contain #{ is built with concat("#", "{"). |
| `:done` | `:done` | A keyword: a name as a value. It may not end in ? or !. |
| `[1, "a"]` | `(list 1 "a")` | A list. Indexing is nth(i, xs); blue has no xs[i]. |
| `{a: 1, "k" => 2}` | `(hash-map :a 1 "k" 2)` | A map. `a:` is the keyword key :a; `=>` takes any key. Read with get(m, k), extend with assoc(m, k, v). |
| `x = 5` | `(define x 5)` | A binding, only as a statement. There is no `let`; a binding lasts to the end of its body. |
| `f(x, y)` | `(f x y)` | A call. This is the one form the formatter writes. |
| `x.f(y)` | `(f x y)` | A method-style call: the receiver becomes the first argument. Formatted as f(x, y). |
| `xs \|> f(a)` | `(f xs a)` | A pipe: the value becomes the FIRST argument, so it suits data-first words. map(f, xs) is function-first: xs \|> map(f) is map(xs, f), an error. |
| `!x` | `(not x)` | Negation. `not(x)` is the same tree. |
| `-x` | `(- 0 x)` | Unary minus. The formatter writes 0 - x as -x. |
| `use("retsu")` | `(use "retsu")` | Import a bidama by name, found on BLUE_PATH. Every definition it makes joins one flat namespace. |
| `throw(error(:parse, "bad row"))` | `(throw (error :parse "bad row"))` | Raise. error(kind, message) alone only builds the value; throw raises it, and uncaught it fails the run. |
| `try(risky(), catch(e(), fallback(e)))` | `(try (risky) (catch (e) (fallback e)))` | Catch a throw. The binding is written as a call, e(). error?(e) is true inside; the kind and message are not readable, so return refusals as data when a caller must tell them apart. |

## Operators

Higher binding power binds tighter.

| operator | binding power | lowers to | meaning |
|---|---|---|---|
| `\|\|` | 1, 2 | `or` | Logical or: the left value if truthy, otherwise the right; the right is evaluated only when needed. |
| `&&` | 3, 4 | `and` | Logical and: the right value if the left is truthy, otherwise the left; short-circuits. |
| `==` | 5, 6 | `equal?` | Structural equality over every value (okite D0001): 4 == 4.0, lists and maps by content, nil only equals nil. |
| `!=` | 5, 6 | `not=` | Exactly not(a == b) (okite D0002). |
| `<` | 5, 6 | `<` | Numeric less-than. A string operand is a type error: order text with compare(a, b). |
| `<=` | 5, 6 | `<=` | Numeric less-than-or-equal. Numbers only, like <. |
| `>` | 5, 6 | `>` | Numeric greater-than. Numbers only, like <. |
| `>=` | 5, 6 | `>=` | Numeric greater-than-or-equal. Numbers only, like <. |
| `+` | 7, 8 | `+` | Numeric addition; an Int and a Float give a Float. Not string concatenation: interpolate instead. |
| `-` | 7, 8 | `-` | Numeric subtraction. Written before an operand with nothing on its left, it is unary minus: -n. |
| `*` | 9, 10 | `*` | Numeric multiplication. |
| `/` | 9, 10 | `/` | Division that never truncates (okite D0008): 7 / 2 is 3.5, while 6 / 2 stays the Int 3. Integer division is floor(a / b). |
| `%` | 9, 10 | `mod` | Euclidean remainder: never negative, so (0 - 7) % 3 is 2, not -1. A zero divisor is a runtime error. |

## Reserved words

| word | meaning |
|---|---|
| `if` | `if c … elsif d … else … end`: an expression; its value is the branch taken, nil when none is. |
| `unless` | `unless c … end`: `if !c`. The formatter writes it as `if !c`. |
| `def` | `def name(a, b) … end`: a named function; its value is the last expression. Parameters may be typed: `def f(n: Int) -> Int`. |
| `defmacro` | `defmacro name(x) quote … unquote(x) … end end`: a macro, a rewrite of the unevaluated form. |
| `quote` | `quote … end`: the form itself as data, not its value. Used inside `defmacro`. |
| `unquote` | `unquote(x)`: inside `quote`, splice in the value of `x`. |
| `unquote_splice` | `unquote_splice(xs)`: inside `quote`, splice the items of the form `xs` in place, not the form itself. |
| `test` | `test "what must hold" … end`: a test block, run by `blue test` and ignored by `blue run`. |
| `assert` | `assert expr`: inside a test, fail it unless `expr` is truthy; the failure quotes the expression. |
| `fn` | `fn(x) x * 2 end`: an anonymous function, a value. Blue has no brace or do blocks. |
| `case` | `case v when 1 … when 2 … else … end`: compares with `==`; it does not destructure. |
| `do` | Reserved and refused: blue has no do-blocks. Pass `fn(x) … end` instead. |
| `end` | Closes `def`, `defmacro`, `if`, `case`, `fn`, `test` and `quote`. |
| `else` | The branch of `if` or `case` taken when nothing before it matched. |
| `elsif` | A further condition in an `if` chain; the formatter writes nested `else if` as `elsif`. |
| `true` | The boolean true. |
| `false` | The boolean false. Only `false` and `nil` are falsy; 0, "" and [] are truthy. |
| `nil` | The absent value. It is not `[]` (okite D0004), and only `nil == nil`. |

## Built-in names

## Bluefile words

A Bluefile is a blue program that may call only these words.

| word | declares |
|---|---|
| `package(name, version)` | The project's or package's name and version; exactly once per Bluefile. |
| `needs(name, range)` | A dependency on a package and a version range ("^0.1"); a package's source must use() every package it needs. |
| `posture(when)` | The posture floor a package requires: "sealed", "preceding" or "anytime". |
| `source(name, url, dir)` | A named external distribution root, fetched from a flake URL and pinned in Bluefile.lock by `blue lock`. |
| `packages(dir)` | A local directory whose subdirectories are packages: each is built, tested (`bidama-test-<pkg>`) and gated for collisions. |
| `run(name, file[, reads])` | A program run as its own cached derivation, writing into $RUN_OUT; `reads` names runs whose outputs it reads. |
| `tool(name)` | A nixpkgs attribute put on PATH for the project's runs, checks, apps and generators. |
| `check(name, file)` | A test file run as `checks.<name>` with `blue test`. A file with no test blocks fails. |
| `app(name, file)` | A program exposed as `nix run .#<name>`. |
| `generate(name, output, program[, inputs])` | A committed file and the program that writes it (to $GEN_OUT): `packages.generated-<name>` and a freshness check. `inputs` lists the project paths the program reads, found under $GEN_ROOT. |
| `catalog(path)` | Where the mokuroku catalogue of the `packages` roots is committed; gated fresh. |
